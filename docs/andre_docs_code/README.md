social features**. Read these instead of the source code when you need to use
them. Questions go to André, and the answers end up in `whys.md`.

| Doc | Read it when |
|---|---|
| [`database.md`](database.md) | you need tables, sessions, friend requests or schema changes |
| [`auth.md`](auth.md) | you need to hash/check passwords, handle logins, or call the auth API |
| [`whys.md`](whys.md) | you wonder *why* something is built the way it is |
